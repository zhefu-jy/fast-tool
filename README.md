# fast-tool

A simple, fast, and portable desktop quick navigation tool built with Neutralinojs.

## Features
- Dark/Light mode theme
- Add and manage local folders and URLs
- Top-pin feature for frequently used items
- System tray support
- Portable: Data is safely stored in the system AppData directory

## Build
```bash
npx @neutralinojs/neu build
node patch-icon.js
```
